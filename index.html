Keyboard shortcuts

Use Tab / Shift + Tab to navigate and Enter / Space to activate controls. Esc closes dialogs. Shortcuts use Alt + Shift (Option + Shift on Mac).

Library: Up / Down moves between papers, Enter / Space opens a paper. Reader: Up / Down and Page Up / Down scroll, Left / Right changes pages, Home / End jumps to the first / last page.

Press Alt + Shift + H to activate the PDF text cursor. Up / Down scrolls the reader in either reading mode. Left / Right moves by character; Shift + Left / Right selects text. Ctrl (Option on Mac) + Left / Right moves by word. Press Alt + Shift + H again to save it as a highlight. Page Up / Down or Alt + Up / Down changes pages. Esc exits the text cursor.

Shortcuts do not trigger ordinary letter commands while typing.
